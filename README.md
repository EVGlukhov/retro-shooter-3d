# Retro Shooter 3D

Браузерный ретро-шутер на арене, созданный на TypeScript, Three.js и Vite. Сражайтесь с врагами Tank-Jr, собирайте патроны и найдите выход.

## Управление

- `E` / `D` — идти вперёд / назад
- `S` / `F` — идти влево / вправо
- Мышь — осмотр
- Левая кнопка мыши — выстрел из рельсотрона
- `Пробел` — прыжок
- `Esc` — пауза

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
